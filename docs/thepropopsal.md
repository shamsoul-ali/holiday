## Part 1 — Equity Offering for RM 500K

**Raise target:** RM 500,000
**Stage:** Early Seed (product built, early traction stage)

### Recommended Structure

| | Amount |
|---|---|
| Pre-money valuation | RM 7,000,000 |
| Investment | RM 500,000 |
| Post-money valuation | RM 7,500,000 |
| **Investor ownership** | **6.67%** |

This is the sweet spot — founder-friendly while still attractive for the investor.

### Why 6–8% Is Ideal

- **3–4%** — investor feels the stake is too small
- **10–15%** — too much dilution too early
- **6–8% for RM 500K** — very reasonable at this stage in Malaysia/SEA

### Negotiation Range

| Scenario | Pre-money | Investor Gets |
|----------|-----------|---------------|
| Strong investor (push up) | RM 8,000,000 | 5.88% |
| Recommended | RM 7,000,000 | 6.67% |
| Lowest acceptable | RM 6,000,000 | 7.70% |

> Do NOT go below RM 5M valuation unless desperate. Do NOT cross 10% for RM 500K.

## Part 4 — Key Terms

### Include (Clean & Fair)

| Term | Detail |
|------|--------|
| Liquidation Preference | 1x non-participating |
| Anti-dilution | Weighted average |
| Board | 1 observer seat (not full board seat at this stage) |
| Pro-rata Rights | Yes, for future rounds |
| Information Rights | Standard quarterly reporting |
| ESOP | 10% reserved |

### Avoid

- Participating preferred
- Multiple liquidation preferences
- Full board control by investor

> Keep it founder-protective.

## Part 5 — Strategic Context

### What This RM 500K Is For

This is **not** for scaling big. It is for:

1. **Proving traction** — users, bookings, GMV
2. **Reducing risk** — product-market fit validation
3. **Setting up the next round** — strong metrics for Series Seed/A

### Next Round Target

| | |
|---|---|
| Raise | RM 3–5M |
| Target valuation | RM 25–35M |
| Expected timeline | 12–18 months post-seed |

Seed investors want to see a **3–5x valuation jump** to the next round.

### Smart Structuring

Structure the round as:

| | |
|---|---|
| Target raise | RM 500,000 |
| Minimum close | RM 200,000 |
| Oversubscription cap | RM 1,000,000 |

This allows you to say: *"We are oversubscribing up to RM 1M if a strategic investor joins"* — which increases perceived demand.
