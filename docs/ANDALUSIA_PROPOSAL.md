## 🏗️ Technical Architecture

### Frontend
- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Responsive, Islamic-themed design
- **Framer Motion** - Smooth animations
- **PWA Support** - Offline-capable, installable

### Backend
- **FastAPI** - High-performance Python API
- **PostgreSQL** - Reliable database with pgvector for AI
- **Redis** - Fast caching for pricing data
- **Celery** - Background job processing

### AI & Integrations
- **OpenAI GPT-4** - Itinerary generation
- **Anthropic Claude** - Customer support chatbot
- **Amadeus API** - Flight inventory
- **Booking.com** - Hotel inventory
- **Stripe/FPX** - Payment processing

### Security & Compliance
- **HTTPS/SSL** - Secure connections
- **Data Encryption** - Customer data protection
- **GDPR/PDPA Compliant** - Privacy regulations
- **PCI-DSS** - Payment card security
- **Regular Backups** - Data integrity

## 📱 Sample User Journey

### Scenario: Puan Aminah wants to book Umrah for family of 4

1. **Discovery**
   - Visits andalusiatravel.com (or new domain)
   - Sees "Jemputan ke Tanah Suci" hero banner
   - Clicks "Tempah Umrah Sekarang"

2. **Planning**
   - Enters: Family (4 pax), Budget (RM 25,000), Dates (June 2026)
   - AI generates 3 package options:
     - Economy: RM 19,500 (save RM 5,500)
     - Standard: RM 24,800 (within budget) ⭐ Recommended
     - Premium: RM 32,500 (upgrade RM 7,500)

3. **Comparison**
   - Views side-by-side hotel locations on map
   - Sees Malaysia Airlines flights included
   - Reads mutawif bios and reviews
   - Watches kursus umrah preview video

4. **Booking**
   - Selects Standard package
   - Chooses installment plan (6 months, 0% interest)
   - Pays deposit (RM 2,000) via FPX
   - Receives instant confirmation & WhatsApp

5. **Pre-Departure**
   - Accesses self-service portal
   - Completes kursus umrah online
   - Downloads packing list & checklist
   - Joins WhatsApp group with other jemaah

6. **Post-Trip**
   - Receives survey for feedback
   - Earns loyalty points
   - Refers 2 friends (gets RM 500 credit)
   - Books again next year (VIP package)

**Time from landing page to booking: 18 minutes**
*(Traditional process: 3-5 days, multiple phone calls)*
